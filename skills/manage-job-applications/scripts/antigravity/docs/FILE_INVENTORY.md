## 2. Known Limitations & Untested Paths

1. **Sanitized Originals Modified for Parameterization:** Unlike unmodified snapshots, scripts in `src/originals_sanitized/` were refactored to replace hardcoded PII, OAuth secrets, Sheet IDs, and personal Windows paths with `src/lib/config.js`, `src/lib/secrets.js`, `src/lib/storage.js`, and `--submit` safety switches. Only offline modules (`config.js`, `secrets.js`, `storage.js`, `resolveCityHeader`, `buildCompliantHtml`, syntax checks, and PII scanning) were executed in this sanitized repository; **live ATS submissions, Chrome CDP scripts, and Google Sheets network calls in `src/originals_sanitized/` were NOT re-run against external sites after sanitization** (to respect read-only / no-apply / no-publish constraints).
2. **Dynamic ATS Custom Question Selectors:** Custom question IDs on Ashby, Greenhouse, and Workday (`question_*`, `survey:*`, `primaryQuestionnaire--*`) vary per employer posting. Scripts targeting custom survey questions (`apply_enpal_ashby.js`, `apply_bolt_and_flix.js`, `step47_fill_sumup_embed.js`) retain generic contact/resume/consent handling; installers must inspect new employer forms (`?questions=true` on Greenhouse or CDP DOM inspection) before adding employer-specific question mappings.
3. **Interactive Gates Remain Human-Supervised:** Email OTPs, passkeys, WebAuthn prompts, `hCaptcha`/`reCAPTCHA`/Turnstile, and portal email-validation quirks require manual resolution in the shared Chrome CDP browser.
4. **Google OAuth Initial Setup Not Bundled:** Users choosing `STORAGE_BACKEND=google` must create their own Google Cloud OAuth 2.0 Desktop client, authorize `drive` and `spreadsheets` scopes, and save the refresh token JSON at `GOOGLE_TOKEN_PATH` (`0600`). Users without Google Workspace should leave `STORAGE_BACKEND=local` (the default).
5. **Cloud SaaS Schedules Cannot Be Exported as Cron Files:** Any ChatGPT Tasks or Gemini Scheduled Actions are managed inside vendor web UIs and cannot be exported into this repository directly; local cron scheduling requires an Antigravity `schedule` sidecar, OS Task Scheduler, or `cron`.
