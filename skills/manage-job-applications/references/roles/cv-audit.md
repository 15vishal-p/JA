# CV Audit

Independently examine the exact exported CV against the current JD, verified candidate evidence and user rules. Read [audit research](../../resources/cv-audit.md) and [the evidence contract](../workflow.md). Inspect the artifact itself, even when CV Creation reports success.

## Work

1. Match employer/requisition, source JD, file reference and version. Confirm the file opens, is complete and comes from the required editor when applicable. Missing artifact access or unavailable page rendering makes the corresponding checks incomplete.
2. Compare every substantive claim to its evidence. Check titles, employers, dates, education, tools, metrics, languages, project links, contact details and location wording. Check mandatory JD requirements separately from CV presentation. Flag unsupported facts, stale employer names, invented results and misleading skill levels.
3. Audit each section for relevance and depth. Check tailored headline/summary, evidence-backed duties, role-appropriate ordering, project selection, duplicate skills and required inclusions. Assess whether a career pivot has genuine technical evidence. Rewording unrelated work cannot establish missing professional experience.
4. Extract the PDF text and inspect reading order and field survival. Render every page and examine legibility, clipping, overlaps, glyphs, page breaks, spacing and content balance. Check required page count and visible sections. Strong candidate fit does not pass a sparse or poorly exported CV.
5. Record a separate manual CV-quality estimate using qualifications 40, duty alignment 25, verified evidence 15, clarity/targeting/parsing 10 and application readiness 10. Explain the awarded points and deductions. Keep the discovery fit score separate. Neither estimate is an employer ATS score, interview probability or reason to inflate wording.
6. Issue `Pass`, `Revise` or `Blocked`. Pass requires all mandatory factual, artifact and user-rule checks completed without unresolved defects and the user's quality criteria satisfied. Unknown checks cannot pass by assumption. A score alone cannot override a defect.

## Findings and handoff

For each finding, record severity, exact page/section, observed issue, relevant JD/user rule or source evidence, and required correction. Immediately notify CV Creation and give the user a concise non-secret summary of mistakes and blocked application work. Escalate unresolved factual questions to the user with the specific missing fact.

Send Application the employer/requisition, exact audited artifact reference and version or checksum, audit time, verdict, completed checks, quality breakdown and current eligibility/fit record. Only `Pass` releases that exact artifact. A later content/layout edit, replacement file, changed JD or changed material candidate fact invalidates the audit and requires reinspection. Preserve audit history with the previous version.

Retain rejected artifacts as superseded unless the user has authorized cleanup. Keep application status unchanged while correcting CV state. Report defects promptly and verify the replacement before clearing them.
