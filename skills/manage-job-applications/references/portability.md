# Using the workflow with different AI hosts

Treat SKILL.md as portable Markdown instructions. Native skill discovery, automatic invocation, schedules, browser tools and file access vary by host; compatibility does not mean identical capabilities.

| Host capability | How to use this folder |
| --- | --- |
| Native SKILL.md support | Install the folder with the host's documented skill mechanism and invoke its name. Keep references and assets beside SKILL.md. |
| Project or workspace instructions | Add SKILL.md to the project instructions and attach its referenced files; do not assume automatic installation. |
| Chat-only AI | Attach SKILL.md and the relevant references, then request one bounded task. Supply redacted documents where connectors are unavailable. |
| Agent with browser and file tools | Map the generic steps to supported tools and verify every external change. |
| Agent without browsing or authenticated tools | Prepare CV text, checklists and tracker rows from supplied sources; report that live verification or submission was not performed. |

Starting prompt:
“Use manage-job-applications in prepare mode. Read my current verified profile and tracker, reconcile duplicates, and prepare the next missing role-specific CV. Report only verified outputs and blockers.”

Keep one private profile per candidate and a confirmed-answer register with answer, scope, date and source. Keep code and generic instructions public; keep CVs, receipts, screenshots, browser profiles, OAuth data, account identifiers and personal answers private.

Do not reuse another candidate's eligibility, language level, salary minimum, email, street address, employer consent or personal facts. Do not reuse a broad consent answer for a different company's declaration.

This folder is a reusable workflow distilled from a user-supplied Antigravity work report and observed tracker-discovery workflow. It does not include or claim to reproduce the original Node.js scripts, browser session, portal adapters or OAuth helpers. Request a sanitized source export before claiming the original automation was published.
